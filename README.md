# MTRP — Multi Transport Relay Protocol

An open protocol and reference SDK for resilient mesh messaging
across heterogeneous transport channels.

## Channel priority

WiFi → Mobile Data → WiFi Direct → BLE → SMS → LoRa → Store & Forward
